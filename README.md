# The Prompt BAR Downloads

The Prompt BARの公式配布ページです。

このリポジトリは完成版アプリの配布と更新案内のためのものです。
開発用ソースコードは公開していません。

## ダウンロード方法

右側または下部のReleasesから、利用するバージョンの配布用ZIPをダウンロードしてください。

通常利用するファイル：

- `The Prompt BAR_vX.X.X.zip`

`Source code (zip)`および`Source code (tar.gz)`は、GitHubが自動生成する案内用リポジトリのアーカイブです。
The Prompt BAR本体のソースコードや実行用アプリは含まれていません。

## 利用について

The Prompt BARはクローズドソースのアプリケーションです。

無断での改変、再配布、転載、解析結果を利用した模倣版の配布は認めていません。
