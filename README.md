# The Prompt BAR

The Prompt BARは、日本語で書いたイメージを画像生成用の英語プロンプトへ変換するWindows向けツールです。

LM Studioと連携し、以下の形式へ変換できます。

- 英語翻訳
- Danbooruタグ
- 自然文プロンプト
- Anima Prompt
- Forge Neoでの画像生成

日本語で入力した人物、髪型、服装、ポーズ、背景などを整理し、画像生成で使いやすい形へ変換します。

## 主な機能

### 日本語から複数形式へ変換

ひとつの日本語入力から、用途に合わせて以下を作成できます。

- 英語プロンプト
- Danbooruタグ
- 自然文
- Anima Prompt

### Anima Prompt

人物ごとの髪色、目色、衣装、動作を分けながら、Danbooruタグと自然文を組み合わせたプロンプトを作成します。

複数人物を含むシーンにも対応しています。

### Forge Neo連携

生成版では、作成したプロンプトをそのままForge Neoへ送り、画像生成まで行えます。

## 必要なもの

- Windows
- LM Studio
- OpenAI互換APIとして利用できるローカルLLM
- 生成機能を使う場合はForge Neo

## ダウンロード

右側または下部のReleasesから最新版をダウンロードしてください。

通常利用するファイルは次の形式です。

`The Prompt BAR_vX.X.X.zip`

ZIPを展開し、`The Prompt BAR.exe`を起動してください。

GitHub上に自動表示される`Source code (zip)`と`Source code (tar.gz)`は、この配布案内用リポジトリのアーカイブです。

The Prompt BAR本体のソースコードや実行用アプリは含まれていません。
